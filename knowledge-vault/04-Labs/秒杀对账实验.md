# 秒杀对账实验

## 目标

验证 Redis 预扣、RabbitMQ 消息和 MySQL 订单最终一致。

## 对账公式

```text
活动库存 = 已成功订单数量 + 活动剩余库存 + 待补偿数量
```

## 检查项

- Redis 预扣数量。
- MQ 发送和消费数量。
- MySQL 成功订单数量。
- 活动剩余库存。
- 失败记录和补偿状态。
