# TokenMall 页面原型说明

## 1. 设计原则

- 页面结构优先服务业务流程。
- 不做复杂动画、营销首页和大量装饰。
- 用户端负责购买、秒杀和查看 Token。
- 管理端负责商品、库存、订单和活动维护。
- 桌面端优先，移动端保证基本可用。
- 前端通过 REST API 调用后端，不包含业务真数据。

建议技术：

```text
React + TypeScript + Vite
React Router
Axios
Ant Design
TanStack Query
```

## 2. 全局导航

### 用户端

```text
Logo | 首页 | 资源包 | Token Plan | 秒杀 | 我的订单 | Token 账户 | 退出
```

### 管理端

```text
控制台 | 分类 | 商品 | SKU 与库存 | 订单 | 秒杀活动 | 返回商城
```

## 17. 前端交付边界

AI 负责：

- 页面和组件。
- 路由和导航。
- API 客户端。
- Token 保存和 401 处理。
- 表单校验。
- 加载、空状态和错误提示。
- 秒杀结果轮询。

学习者负责：

- 后端接口实现。
- Redis 和 RabbitMQ 内部逻辑。
- 数据库并发和一致性实验。
