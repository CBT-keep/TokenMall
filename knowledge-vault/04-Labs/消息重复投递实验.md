# 消息重复投递实验

## 目标

证明 RabbitMQ 至少一次投递下消费方必须实现幂等。

## 步骤

1. 发送一条支付成功事件。
2. 确认 Token 只发放一次。
3. 使用相同 `eventId` 再次发送。
4. 观察 Token 流水和余额。
5. 增加 `mq_consume_log` 或唯一业务键。
6. 再次重复发送并验证结果。

## 验证标准

- 第一次消息正常处理。
- 重复消息不会增加第二次余额。
- 消费日志能够解释为什么被跳过。
