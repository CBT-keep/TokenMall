# 秒杀系统

## 目标

Token Plan 秒杀需要解决：

- 高并发请求不能直接压垮 MySQL。
- 库存不能超卖。
- 同一用户不能重复抢购。
- Redis 预扣成功后订单必须最终落库。
- 失败消息和对账必须可追踪。

## 演进路线

1. 直接查 MySQL 并更新库存。
2. 并发复现超卖。
3. 使用 MySQL 行锁或乐观锁修复。
4. 使用 Redis Lua 预扣库存。
5. 使用 RabbitMQ 异步下单。
6. 增加消费幂等、失败补偿和对账。
