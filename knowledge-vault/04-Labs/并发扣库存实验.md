# 并发扣库存实验

## 目标

在并发请求下复现库存超卖，并比较不同 MySQL 修复方案。

## 步骤

1. 记录测试前库存。
2. 使用 20 至 100 个并发请求购买同一 SKU。
3. 查询最终库存和成功订单数。
4. 判断是否满足 `初始库存 - 成功数量 = 剩余库存`。
5. 使用 `SELECT ... FOR UPDATE` 或条件更新修复。
6. 重复实验并比较结果。

## 观察指标

- 成功请求数。
- 失败请求数。
- 最终可用库存。
- 超卖数量。
- 死锁或锁等待次数。
